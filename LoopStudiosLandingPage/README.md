# Loopstudios Landing Page

A responsive and interactive **Loopstudios Landing Page** built with modern frontend practices.

Built with **React and Tailwind CSS**, focusing on **responsive layout, component-based architecture, dynamic data rendering, and interactive UI effects**.

This project is a solution to a **Frontend Mentor challenge**.

## Live Demo

https://loop-studios-landing-page-rose.vercel.app/

## Features

### Responsive Header & Navigation

- Responsive navigation for mobile, tablet, and desktop
- Mobile fullscreen navigation menu
- Animated mobile menu transition
- Responsive hero section with different images for mobile and desktop
- Navigation links with hover effects

---

### About Section

- Responsive image handling for mobile and desktop
- Overlapping image and text layout on larger screens
- Responsive typography and spacing
- Semantic content structure

---

### Creations Gallery

- Dynamic creation cards rendered from data
- Separate desktop and mobile background images
- Responsive grid layout
- Image overlay for improved text readability
- Interactive hover effects
- Text color and image opacity transitions
- Responsive "See all" buttons

---

### User Experience

- Smooth hover transitions
- Interactive navigation menu
- Responsive layouts across different screen sizes
- Clear visual hierarchy and typography
- Mobile-first approach

---

## Technologies Used

### React / JavaScript

- Functional components
- useState for mobile navigation state
- Event handling
- Component-based architecture
- Dynamic rendering with `map()`

---

### Tailwind CSS

- Utility-first styling
- Responsive breakpoints
- Flexbox & Grid layouts
- Background images
- Positioning and overlays
- Hover and transition effects
- Responsive typography
